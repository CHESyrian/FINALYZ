# First 15 Ratios

---

| الفئة             | النسبة المالية          | الاختصار  | الرمز | قانون الحساب                                                               | الوحدة  |
| ----------------- | ----------------------- | --------- | ----- | -------------------------------------------------------------------------- | ------- |
| **Liquidity**     | Current Ratio           | CR        | (CR)  | (\frac{Current\ Assets}{Current\ Liabilities})                             | مرة (x) |
| **Liquidity**     | Quick Ratio             | QR        | (QR)  | (\frac{Current\ Assets-Inventory-Prepaid\ Expenses}{Current\ Liabilities}) | مرة (x) |
| **Liquidity**     | Cash Ratio              | CaR       | (CaR) | (\frac{Cash+Cash\ Equivalents}{Current\ Liabilities})                      | مرة (x) |
| **Profitability** | Gross Margin            | GPM       | (GPM) | (\frac{Gross\ Profit}{Revenue}\times100)                                   | %       |
| **Profitability** | Operating Margin        | OPM       | (OPM) | (\frac{Operating\ Income}{Revenue}\times100)                               | %       |
| **Profitability** | Net Margin              | NPM       | (NPM) | (\frac{Net\ Income}{Revenue}\times100)                                     | %       |
| **Profitability** | Return on Assets        | ROA       | (ROA) | (\frac{Net\ Income}{Average\ Total\ Assets}\times100)                      | %       |
| **Profitability** | Return on Equity        | ROE       | (ROE) | (\frac{Net\ Income}{Average\ Shareholders' Equity}\times100)               | %       |
| **Solvency**      | Debt Ratio              | DR        | (DR)  | (\frac{Total\ Debt}{Total\ Assets}\times100)                               | %       |
| **Solvency**      | Debt-to-Equity          | D/E       | (D/E) | (\frac{Total\ Debt}{Shareholders' Equity})                                 | مرة (x) |
| **Solvency**      | Equity Ratio            | ER        | (ER)  | (\frac{Shareholders' Equity}{Total\ Assets}\times100)                      | %       |
| **Solvency**      | Interest Coverage Ratio | ICR       | (ICR) | (\frac{EBIT}{Interest\ Expense})                                           | مرة (x) |
| **Efficiency**    | Asset Turnover          | ATR / ATO | (ATO) | (\frac{Revenue}{Average\ Total\ Assets})                                   | مرة (x) |
| **Efficiency**    | Receivables Turnover    | RTR / ART | (RT)  | (\frac{Net\ Credit\ Sales}{Average\ Accounts\ Receivable})                 | مرة (x) |
| **Efficiency**    | Inventory Turnover      | ITR       | (ITR) | (\frac{COGS}{Average\ Inventory})                                          | مرة (x) |


---

| المتغير                | الاسم                      | المعنى                                                        |
| ---------------------- | -------------------------- | ------------------------------------------------------------- |
| (Current\ Assets)      | الأصول المتداولة           | الأصول المتوقع تحويلها إلى نقد خلال الفترة التشغيلية/12 شهرًا |
| (Current\ Liabilities) | الخصوم المتداولة           | الالتزامات المستحقة عادة خلال 12 شهرًا                        |
| (Cash)                 | النقدية                    | النقد المتاح                                                  |
| (Cash\ Equivalents)    | معادلات النقد              | استثمارات قصيرة الأجل عالية السيولة                           |
| (Inventory)            | المخزون                    | مخزون البضاعة/المواد                                          |
| (Prepaid\ Expenses)    | المصروفات المدفوعة مقدمًا  | مصروفات دُفعت مقدمًا وليست أصولًا سريعة التحول إلى نقد        |
| (Revenue)              | الإيرادات                  | إجمالي إيرادات النشاط                                         |
| (Gross\ Profit)        | مجمل الربح                 | (Revenue - COGS)                                              |
| (COGS)                 | تكلفة المبيعات             | Cost of Goods Sold                                            |
| (Operating\ Income)    | الربح التشغيلي             | EBIT في كثير من الحالات                                       |
| (Net\ Income)          | صافي الربح                 | الربح بعد المصروفات والفوائد والضرائب                         |
| (EBIT)                 | الربح قبل الفوائد والضرائب | Earnings Before Interest and Taxes                            |
| (Interest\ Expense)    | مصروف الفوائد              | تكلفة التمويل/الفوائد                                         |
| (Total\ Assets)        | إجمالي الأصول              | مجموع الأصول                                                  |
| (Total\ Debt)          | إجمالي الديون              | الالتزامات التي تحمل طبيعة تمويلية/فوائدية                    |
| (Shareholders' Equity) | حقوق الملكية               | الأصول ناقص الالتزامات                                        |
| (Average\ Assets)      | متوسط الأصول               | (\frac{Beginning + Ending}{2})                                |
| (Average\ Equity)      | متوسط حقوق الملكية         | (\frac{Beginning + Ending}{2})                                |
| (Average\ Inventory)   | متوسط المخزون              | (\frac{Beginning + Ending}{2})                                |
| (Average\ AR)          | متوسط الذمم المدينة        | (\frac{Beginning + Ending}{2})                                |
